# Future UI Text Policy

## Default

All newly generated UI review drafts and formal assets are text-clean by default.

Remove:

- page titles;
- descriptions and instructions;
- localized action labels;
- item names, quality names and status text;
- prices, quantities, percentages, timers and other dynamic numbers.

Retain:

- `X` close symbol;
- `?` help symbol;
- `+` and `-` quantity symbols;
- arrows and other functional identification symbols.

## Surface reconstruction

Removing text must restore the complete underlying black-steel, card, slot or button surface. Button and slot safe interiors remain fully opaque.

## Reference immutability

Files under `01_References/Style/Standards/` are never edited to enforce this policy. They remain unchanged canonical evidence. The policy is applied only to new project generation and project outputs.

## Style precedence

```text
Wireframe = structure
Cook = primary appearance
Equipment Identification = secondary supplement
Text policy = clean new output, immutable references
```
