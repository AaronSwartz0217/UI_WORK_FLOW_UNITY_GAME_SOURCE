## Production use

- This directory is a read-only reference library, not a formal project or output directory.
- Select one whiteframe at a time.
- Copy the selected file into `../../02_InputQueue/<category>/<ProjectId>/Wireframe/` before production.
- The selected whiteframe controls layout, ratio, panel count, coordinates and hierarchy only.
- Cook remains the primary visual standard; Equipment Identification remains secondary.
- New full-UI drafts follow `../ReferenceNotes/FUTURE_UI_TEXT_POLICY.md` and omit ordinary/localized text and dynamic numbers.
