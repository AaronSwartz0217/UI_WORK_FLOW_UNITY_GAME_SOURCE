# Shared Component Reference Index

These six RGBA PNG files are the canonical shared style-component references for this workflow.

| Category | File | Size | Intended use |
|---|---|---:|---|
| CloseButtons | `Shared_CloseButton_RedX_Reference_52x56.png` | 52x56 | close-button material, bevel, red warning color, retained X symbol |
| Buttons | `Shared_HelpButton_AmberQuestion_Reference_52x56.png` | 52x56 | help-button material and retained question-mark symbol |
| Buttons | `Shared_LongButton_DarkNormal_Reference_354x81.png` | 354x81 | long-button normal/baseline appearance |
| Buttons | `Shared_LongButton_AmberHighlight_Reference_354x81.png` | 354x81 | matching amber highlight appearance |
| Slots | `Shared_SquareSlot_AmberCorners_Reference_94x90.png` | 94x90 | compact slot/inset panel with amber corner accents |
| PanelBorders | `Shared_LargeSquarePanel_BlackSteel_Reference_227x227.png` | 227x227 | large square forged-steel panel/border language |

Usage rules:

- Inspect all six before producing a UI that contains related component classes.
- Copy used references into the active project `in/` folder and record them in project documentation.
- Use them for style and component treatment; do not replace the wireframe layout with their dimensions.
- Keep the two 354x81 long-button images paired as one state-style reference family.
- Preserve functional X and question-mark symbols. Remove text only from non-symbol buttons, while keeping their interiors opaque and visually reconstructed.
- Never non-uniformly stretch these references.
