# Cutout Method

The clean background was generated by removing only the four approved glass controls from the approved full-screen draft, then center-cropping to 1464×828.

The input and button PNGs were generated inside Unity from the supplied `毛玻璃.json` values using a rounded-box signed-distance field. Pixels outside the rounded silhouette are alpha 0. Interior pixels preserve semi-transparency for the runtime glass shader.

For the action button family, RGBA canvas size and alpha bytes are identical across all four states; only RGB tint changes. This avoids state switching jumps and clipped corners.
