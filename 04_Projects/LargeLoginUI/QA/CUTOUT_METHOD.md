# Cutout Method

The clean background was generated by removing only the four approved glass controls from the approved full-screen draft, then center-cropping to 1464×828.

The input and button PNGs were generated inside Unity from the supplied `毛玻璃.json` values using a rounded-box signed-distance field. Pixels outside the rounded silhouette are alpha 0. Interior pixels preserve semi-transparency for the runtime glass shader.

For the action button family, RGBA canvas size and alpha bytes are identical across all four states; only RGB tint changes. This avoids state switching jumps and clipped corners.

The CharacterSetup components are independently baked from the same approved preset, not rectangular crops from the full-screen screenshot. The rounded-box signed-distance field touches the formal canvas at each straight edge, so no arbitrary transparent border remains; only the true rounded corners are alpha 0. The parent main panel excludes the name input and current-equipment slot, which are separate child assets.

Equipment cards use one 184×164 union canvas for `Normal`, `Hover`, `Pressed`, `Disabled`, and `Selected`. The footer is part of the card surface; its localized label remains a TMP child. Enter-game uses one 368×72 union canvas for all four required interaction states. All CharacterSetup surfaces are explicitly classified as glass, so intentional translucent interiors are allowed while pixels outside each silhouette remain alpha 0.
